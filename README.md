# BLOG

深夜のアニメ、初期の家庭用ゲーム機、二〇〇〇年代の個人サイトをイメージした、静的な日本語の個人ブログです。

## GitHub Pages で公開する

1. GitHubで新しいリポジトリを作成します。
2. このフォルダの内容をリポジトリのルートへプッシュします。
3. **Settings → Pages** を開きます。
4. **Build and deployment** で **Deploy from a branch** を選択します。
5. Branchを `main`、フォルダを `/ (root)` に設定して保存します。

すべてのリンクは相対パスなので、ユーザーサイトとプロジェクトサイトの両方で動作します。

## 記事を編集・追加する

すべての記事は `content/posts.json` だけで管理します。既存の記事を編集するか、最後の `{ ... }` ブロックを複製して、番号、URL名、日付、タイトル、概要、本文を変更してください。

編集後、プロジェクトのフォルダで次を実行します。

```powershell
node scripts/build-posts.js
```

このコマンドが個別の記事ページを作り、ホームページと記事一覧を自動更新します。生成されたHTMLを直接編集する必要はありません。

### 記事に画像を追加する

画像を `assets/images/` に保存し、記事の `subtitle` の後などに次の項目を追加します。

```json
"images": [
  {
    "src": "assets/images/my-photo.jpg",
    "alt": "画像の説明",
    "caption": "画像の下に表示する文"
  }
],
```

`alt` は画像を見られない人のための説明です。`caption` は不要なら空欄にできます。追加後、通常どおりビルドコマンドを実行してください。

## デザインを変更する

配色、光彩、境界線、背景などは `assets/style.css` 冒頭のCSS変数で調整できます。
